Cause and effect lab

Two questions this page answers with the real recorded ledger: which single argument decided a verdict, and what rule would fire for inputs you choose. Nothing here is simulated data: section one reads the published dossiers, section two replays the same policy that produced them.

1. Drop one argument from a real decision

Every dossier already carries its own sensitivity analysis: for each argument, the edge and the action that would remain if that argument were removed. Pick a dossier and look for the red rows: those are the arguments the verdict literally depends on.

2. Policy playground: replay the rules yourself

This mirrors verdict_desk/agents_v2.py: the entry threshold, the volatility rule, the freshness gate and the fail-closed behaviour. Move the sliders and the rule that fires is named, not hidden. It treats each side as a single argument of the weight you set, which is the same arithmetic the judge runs.

Simulated decisions only: this project never places or signs an order. Rules v3 keeps the v2 sizing and adds named declined states.
