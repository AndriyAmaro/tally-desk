A trading agent that shows its receipts

Verdict Desk decides on paper trades and answers for every model call it makes. Each call goes through the Otari gateway on an open-weight model and leaves a receipt, sealed in a hash-chained ledger that anyone can verify and replay offline.

See one cycle, call by call Verify a record in your browser Read the audit

Nothing to install and no account: these pages read the public ledger file and check it in your browser. No real-money order is ever placed. The trading agent is the reference workload: the receipts, the hash chain and the verifier work for any agent that calls models through a gateway (what a second agent plugs in).
